# BountyLoop Brand Guide

> **Version 1.0 — Locked identity from the approved logo.**

## Colours

| Token | Hex | Usage |
|---|---|---|
| Brand green | `#2D5A3D` | Primary buttons, nav, card headers, "Bounty" wordmark |
| Brand amber | `#D98E32` | Accents, highlights, CTA, "Loop" wordmark, circular leaf |
| Neutral white | `#FFFFFF` | Backgrounds, card surfaces |
| Text dark | `#1A2E1F` | Body text, dark mode backgrounds |
| Text muted | `#6B8069` | Secondary text, labels |

## Logo

Two assets committed here:

- `bountyloop_logo.png` — icon only (circular arrow loop enclosing amber leaf)
- `bountyloop_logo_wordmark.png` — icon + wordmark ("Bounty" green, "Loop" amber)

### Usage rules

1. Minimum size: 32 px height for icon, 80 px width for wordmark.
2. Clear space: at least half the icon height on all sides.
3. Do **not** stretch, rotate, recolour, or apply effects.
4. On dark backgrounds, use the white-variant wordmark (to be created if needed).
5. Do **not** hot-link temporary file URLs — always use the committed asset path.

## Typography

- **Primary:** Inter (Google Fonts) — headings and UI labels
- **Fallback:** system-ui, -apple-system, sans-serif
- **Code:** JetBrains Mono or monospace

## Logo icon description

Circular arrow loop in forest green, enclosing a stylised leaf in golden amber.
The loop represents the circular economy — food kept in the community, not in a landfill.
The leaf represents the "bounty" — natural abundance.

## Voice

Warm · Community-centred · Action-oriented · Optimistic · Evidence-based  
Tagline: *"Turn surplus into supper — the AI loop that keeps good food in the community."*

## Do / Don't

✅ "BountyLoop rescued 1.2 kg — that's a meal for a family."  
✅ "Open for donations — 3 recipients within 5 km are waiting."  
❌ "Hazardous food detected." (Never surface the formalin flag as a user-facing claim.)  
❌ "We guarantee food safety." (The CV pipeline is a rescue-assist tool, not a lab.)
